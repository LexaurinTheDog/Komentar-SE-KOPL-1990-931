# Kommentar till köplagen (1990:931)

Kommentar till svensk författning: **Köplag (1990:931)** (SFS 1990:931). Kommentaren omfattar **86 enheter** (82 paragrafer, 1–82 §§, samt övergångsbestämmelserna till SFS 1990:931, 1996:776, 2022:262 och 2022:981) fördelade på 4 kommentarskapitel; vid varje enhet återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 2022:981** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=1990:931](https://rkrattsbaser.gov.se/sfst?bet=1990%3A931) · [data.riksdagen.se/dokument/sfs-1990-931](https://data.riksdagen.se/dokument/sfs-1990-931.json)
